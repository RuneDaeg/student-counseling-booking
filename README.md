# 학생 상담 신청 웹앱

**powered by 여광재 (온양고등학교)**

교사를 위한 상담 예약 시스템입니다. 구글 스프레드시트와 Apps Script만 쓰기 때문에
**서버도, 사용료도, 별도 계정도 필요 없습니다.**

- 학생은 링크를 열어 **날짜·시간을 고르고 고민을 적어** 신청합니다. 로그인하지 않아도 됩니다.
- 교사가 시트에 적어 둔 **상담 불가 날짜·시간은 자동으로 선택이 막힙니다.**
  고를 수 없는 칸에 마우스를 올리면 그 이유("선생님 일정 · 출장")가 뜹니다.
- 학생이 쓴 글은 **AI가 읽고 상담 준비 초안**으로 정리해 교사 메일로 보냅니다.
  첫 질문 문장, 단계별 상담 흐름, 유의할 점, 그리고 **위기 신호 표시**까지 함께 옵니다.
- 학생은 예약번호로 **직접 취소**할 수 있고, 취소한 자리는 바로 다시 열립니다.

기본값은 `2학년 10반 / 13:10·16:30 (수·금은 15:30 추가)` 이며 전부 `설정` 시트에서 바꿉니다.
코드를 고칠 일은 없습니다.

> **AI 초안은 참고용입니다.** 진단이 아니며 판단과 상담은 교사가 합니다.
> 자세한 내용은 아래 [개인정보와 안전](#5-개인정보와-안전에-대해) 을 꼭 읽어 주세요.

## 1. 파일 구성

```
src/          ← Apps Script 에 올라가는 파일 (이것만 있으면 동작합니다)
  appsscript.json    매니페스트(권한·시간대·웹앱 설정)
  Code.gs            웹앱 진입점 (doGet)
  Config.gs          설정 시트 읽기, 날짜·시간 계산
  Setup.gs           최초 설정, 스프레드시트 메뉴
  Slots.gs           예약 가능한 날짜·시간 계산 (불가일 제외)
  Reservation.gs     신청 접수·취소, 교사 알림 메일
  Ai.gs              AI 호출 (Claude / Gemini / GPT), 상담 초안 생성
  Index.html         학생 화면 (구조)
  Stylesheet.html    학생 화면 (디자인)
  JavaScript.html    학생 화면 (동작)

install.sh / install.ps1   설치·업데이트 스크립트
link.sh / link.ps1         이미 만든 프로젝트에 연결 (업데이트용)
tools/                     화면 미리보기용 (배포와 무관)
```

## 2. 설치

두 가지 방법이 있습니다. **방법 A** 는 스프레드시트까지 알아서 만들어 주고,
**방법 B** 는 프로그램 설치 없이 복사·붙여넣기만 합니다. 결과는 같습니다.

### 방법 A — 한 줄로 설치 (Node.js 필요)

먼저 <https://script.google.com/home/usersettings> 에서
**"Google Apps Script API"** 를 사용 설정합니다. (계정당 한 번만)

```bash
git clone https://github.com/RuneDaeg/student-counseling-booking.git
cd student-counseling-booking
sh install.sh          # 윈도우 PowerShell 이면  .\install.ps1
```

구글 로그인 창이 뜨고, 끝나면 **내 드라이브에 스프레드시트가 새로 생기고 코드까지 올라갑니다.**
이후에는 아래 ③④⑤ 만 하면 됩니다. 코드를 고친 뒤 `sh install.sh` 를 다시 실행하면 갱신됩니다.

### 방법 B — 복사해서 붙여넣기 (설치할 것 없음)

1. Google 스프레드시트를 새로 만듭니다. (예: `상담 신청 관리`)
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 **⚙ 프로젝트 설정** 에서 **"appsscript.json 매니페스트 파일 표시"** 를 켭니다.
4. `src/` 안의 파일을 같은 이름으로 만들어 내용을 붙여 넣습니다.
   - `.gs` 는 **파일 + → 스크립트**, `.html` 은 **파일 + → HTML** 로 만듭니다
   - 이름은 확장자 없이 `Config`, `Index` 처럼 입력합니다 (확장자는 자동으로 붙습니다)
   - **HTML 세 개는 이름이 정확해야 합니다.** `Index` 가 `Stylesheet` 와 `JavaScript` 를
     이름으로 불러오기 때문에 하나라도 다르면 화면이 열리지 않습니다
   - 학교 시간대가 다르면 `appsscript.json` 의 `timeZone` 을 바꿉니다

### 이미 만든 프로젝트를 나중에 업데이트하려면

붙여넣기를 다시 할 필요 없습니다. 처음 한 번만 연결해 두면 그다음부터는 두 줄입니다.

**1단계 — 연결 (처음 한 번만)**

Apps Script 편집기 → **⚙ 프로젝트 설정** → **스크립트 ID** 를 복사한 뒤:

```bash
sh link.sh
```

```powershell
.\link.ps1
```

편집기 주소를 통째로 붙여 넣어도 ID만 알아서 골라냅니다.

**2단계 — 업데이트 (그다음부터 매번)**

```bash
git pull
sh install.sh
```

```powershell
git pull
.\install.ps1
```

> **PowerShell 에는 `sh` 가 없습니다.** `sh install.sh` 를 실행하면
> `'sh' 용어가 ... 인식되지 않습니다` 오류가 납니다. `.\install.ps1` 을 쓰세요.
> 거꾸로 Git Bash·macOS·Linux 에서는 `sh` 쪽을 씁니다.
>
> **연결(`link`)을 건너뛰고 `install` 을 먼저 실행하면 스프레드시트가 새로 하나 더 만들어집니다.**
> 기존 시트를 고치려는 것이라면 반드시 연결을 먼저 하세요.
>
> **`clasp push` 는 로컬 파일로 원격을 덮어씁니다.** 편집기에서 직접 고친 내용이 있다면
> 먼저 `clasp pull` 로 받아서 합친 뒤 올리세요.
>
> **올린 코드가 학생 화면에 반영되려면 새 버전으로 배포해야 합니다.**
> 스프레드시트 메뉴와 시트 기능은 올리는 즉시 바뀝니다.
> 배포까지 명령으로 하려면 `clasp deployments` 로 배포 ID를 확인한 뒤
> `clasp redeploy <배포ID> -d "설명"` 을 실행하고 결과를 **배포 관리**에서 확인하세요.

### ③ 최초 설정 실행

1. 스프레드시트로 돌아가 새로고침하면 상단에 **[상담 관리]** 메뉴가 생깁니다.
2. **상담 관리 → ① 최초 설정 실행** 을 누릅니다. 권한 승인 창이 뜨면 허용합니다.
   ("이 앱은 확인되지 않았습니다" 창에서는 **고급 → 프로젝트로 이동**)
3. `설정`, `상담불가`, `예약` 시트 세 개가 만들어집니다.

### ④ AI 키 등록

기본은 Claude 입니다. Gemini·GPT 로 바꾸려면 [4. 다른 AI 로 바꾸기](#4-다른-ai-로-바꾸기) 를 보세요.

1. <https://console.anthropic.com> 에서 API 키를 발급합니다. (`sk-ant-...`)
2. **상담 관리 → ② AI 키 등록 / 변경** 에 붙여 넣습니다.
   키는 스크립트 속성에 저장되며 **스프레드시트에는 남지 않습니다.**
3. **③ AI 연결 테스트** 로 확인합니다.

### ⑤ 배포

Apps Script 편집기 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**

- **실행 계정**: 나 (교사 본인)
- **액세스 권한**: **모든 사용자** — 학생이 로그인 없이 들어올 수 있습니다.
  교내 계정만 받으려면 "○○학교의 모든 사용자"를 고릅니다.

배포 후 나오는 주소를 학생에게 알려 줍니다.
주소는 **상담 관리 → 웹앱 주소 보기** 에서 다시 볼 수 있습니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야
> 학생 화면에 반영됩니다. 주소는 그대로 유지됩니다.

## 3. 매일 쓰는 법

### 상담 못 하는 날 막기 — `상담불가` 시트

| 시작일 | 종료일 | 시작시각 | 종료시각 | 사유 |
| --- | --- | --- | --- | --- |
| 2026-09-14 | | | | 출장 |
| 2026-09-21 | 2026-09-25 | | | 수학여행 |
| 2026-09-17 | | 16:00 | 17:30 | 부장회의 |

- **시작일만** 쓰면 그날 하루 전체가 막힙니다.
- **종료일까지** 쓰면 그 기간 전체가 막힙니다.
- **시각까지** 쓰면 그 시간대만 막힙니다. 나머지 시간은 그대로 신청받습니다.

적어 두면 학생 달력에서 그 날짜가 **취소선과 함께 선택 불가**로 바뀝니다.
(학생이 화면을 열 때마다 다시 계산하므로 따로 새로고침할 일이 없습니다.)

**사유는 학생에게 그대로 보입니다.** 고를 수 없는 날짜나 시간에 마우스를 올리면(휴대폰은 누르면)
`9월 17일 (목) — 선생님 일정 · 부장회의` 처럼 말풍선이 뜹니다. 학생이 봐도 괜찮은 말로 적어 주세요.
사유를 비워 두면 `선생님이 상담할 수 없는 시간이에요` 라고만 나옵니다.

학생에게 보이는 다른 안내 문구는 이렇습니다.

| 상황 | 말풍선 |
| --- | --- |
| 운영하지 않는 요일 | 상담을 받지 않는 요일이에요 |
| 예약 기간 밖 | 신청할 수 있는 기간이 아니에요 |
| 다른 학생이 먼저 신청 | 이미 예약이 찼어요 |
| 오늘의 지난 시간 | 이미 지난 시간이에요 |
| 마감 유예 시간 안 | 신청이 마감됐어요 (상담 시작 60분 전까지) |

### 운영 방식 바꾸기 — `설정` 시트

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 상담 시간대 | `13:10, 16:30` | 학생이 고를 수 있는 시작 시각. 쉼표로 나열합니다 |
| 요일별 추가 시간대 | `수:15:30, 금:15:30` | 그 요일에만 더 여는 시간. 비우면 없음 |
| 상담 1회 시간(분) | `30` | 끝나는 시각을 계산할 때 씁니다 |
| 운영 요일 | `월,화,수,목,금` | 상담을 받는 요일 |
| 고정 학년 / 고정 반 | `2` / `10` | 적어 두면 학생은 **번호와 이름만** 입력합니다. 비우면 학생이 직접 입력 |
| 예약 시작 / 예약 종료 | `1` / `21` | **숫자면** 오늘부터 며칠 뒤, **날짜면** 그 기간 고정. 아래 참고 |
| 같은 시간대 최대 인원 | `1` | 집단상담이면 2 이상으로 |
| 학생 1인 동시 예약 수 | `1` | 중복 신청 막기 |
| 마감 유예 시간(분) | `60` | 상담 60분 전까지만 신청받기 |
| 상담 유형 | 7가지 | 학생이 고르는 주제 목록 |
| 고민 최소 글자수 | `20` | 너무 짧게 쓰는 것 방지 |
| 담당 교사 이메일 | (비움) | 비우면 배포한 계정으로 |
| AI 분석 사용 / 동의 필수 | `TRUE` | AI 기능을 끄거나, 학생 동의가 있을 때만 쓰기 |
| AI 제공자 | `claude` | `claude` / `gemini` / `openai` 중 하나 |
| AI 모델 | (비움) | 비우면 제공자 기본 모델. 아래 표 참고 |
| AI 분석 강도 | `medium` | `low` / `medium` / `high` (Claude 에만 적용) |

**예약 기간 정하는 두 가지 방법**

| 적는 값 | 뜻 | 언제 쓰나 |
| --- | --- | --- |
| 숫자 (`1` / `21`) | 오늘부터 1일 뒤 ~ 21일 뒤. **매일 하루씩 밀립니다** | 상시로 상담을 받을 때 |
| 날짜 (`2026-09-15` / `2026-09-26`) | 그 기간에만 신청을 받습니다. **고정** | 상담 주간처럼 기간이 정해졌을 때 |

- 두 칸을 섞어 써도 됩니다. 예: 시작 `1`, 종료 `2026-10-31` → 내일부터 10월 말까지
- 시작 날짜가 이미 지났으면 **오늘부터**로 자동 조정됩니다
- 종료 날짜가 지나면 학생 화면에 달력 대신
  `상담 신청 기간이 끝났습니다. (9월 26일 (토)까지)` 가 뜹니다.
  이때도 **기존 신청 취소는 계속 가능**합니다
- 날짜는 `2026-09-15`, `2026. 9. 15`, `2026년 9월 15일` 어느 형식이든 됩니다
- 기간을 아무리 길게 적어도 화면에는 최대 366일까지만 만들어집니다 (오타 방지)

**시간대를 바꾸는 예시**

- 매일 4타임: `상담 시간대` 에 `13:10, 15:30, 16:30, 17:00`
- 화요일만 아침 상담 추가: `요일별 추가 시간대` 에 `화:08:20`
- 수·금만 15:30 추가(기본값): `수:15:30, 금:15:30`

값을 바꾸면 **바로 반영**됩니다. 다시 배포할 필요가 없습니다.

### 신청이 들어오면

`예약` 시트에 한 줄이 쌓이고, 10초쯤 뒤 AI 분석이 끝나면 교사 메일로 정리본이 갑니다.

- **AI 요약** — 무엇 때문에 왔는지 2~3문장
- **AI 상담 초안** — 핵심 주제 / 학생의 감정 / 확인할 점 / **바로 쓸 수 있는 첫 질문** /
  단계별 상담 흐름과 예시 대화 / 유의할 점 / 이어질 지원
- **AI 관심신호** — `낮음 / 보통 / 높음` 과 그렇게 본 근거.
  자해·자살·학대·폭력 신호가 보이면 **높음**으로 표시되고 줄 전체가 붉게 칠해집니다.
  이때는 "바로 할 일"이 함께 제시됩니다.

메뉴에서 쓸 수 있는 것:

- **선택한 예약 AI 다시 분석** — 줄을 고르고 누르면 다시 분석합니다.
- **오늘 상담 브리핑 메일 받기** — 오늘 상담 전체를 한 통으로 받습니다.

### 학생이 취소할 때

신청 완료 화면의 **예약번호**(예: `260908-AB3D`)와 이름을 넣으면 학생이 직접 취소합니다.
취소된 자리는 곧바로 다시 신청 가능해집니다.

## 4. 다른 AI 로 바꾸기

Claude 말고 **Gemini** 나 **GPT** 로도 쓸 수 있습니다. 프롬프트와 결과 형식은 셋이 같아서
`설정` 시트에서 **[AI 제공자]** 를 바꾸고 그 회사 키를 넣으면 끝입니다. 코드는 건드리지 않습니다.

| AI 제공자 | 기본 모델 | 키 받는 곳 | 키 모양 |
| --- | --- | --- | --- |
| `claude` | `claude-opus-5` | console.anthropic.com | `sk-ant-...` |
| `gemini` | `gemini-2.5-flash` | aistudio.google.com/apikey | `AIza...` |
| `openai` | `gpt-4o` | platform.openai.com | `sk-...` |

**바꾸는 순서**

1. `설정` 시트에서 **[AI 제공자]** 를 `gemini` 처럼 바꿉니다
2. **[AI 모델]** 은 비워 두면 위 기본 모델을 씁니다. 다른 모델을 쓰려면 정확한 이름을 적습니다
3. **[상담 관리] → ② AI 키 등록 / 변경** 에서 그 회사 키로 바꿉니다
4. **③ AI 연결 테스트** 로 확인합니다

제공자와 모델이 어긋나면(예: 제공자는 `gemini` 인데 모델이 `claude-opus-5`) 무엇이 어긋났는지
알려 주고 멈춥니다. 모델 이름은 회사마다 자주 바뀌니 각 사이트의 모델 목록을 확인해 주세요.

> 학교에서 이미 구글을 쓰고 계신다면 **Gemini** 가 시작하기 쉽습니다. 무료 사용량이 있고
> 결제 정보를 따로 넣지 않아도 키를 받을 수 있습니다.

**또 다른 AI 를 붙이고 싶다면** `src/Ai.gs` 만 고치면 됩니다.
`AI_PROVIDERS` 에 항목을 하나 추가하고, `callGemini_` 를 흉내 낸 함수를 만들어
`callAi_` 의 분기에 연결하면 나머지(프롬프트, 시트 기록, 메일, 위기 신호)는 그대로 동작합니다.

## 5. 개인정보와 안전에 대해

- AI에게 보내는 것은 **학년 / 상담 주제 / 학생이 쓴 글**뿐입니다.
  **이름·반·번호는 보내지 않습니다.** 연락처는 아예 받지 않습니다.
- 학생 화면에는 AI 사용 동의 체크가 있고, 동의하지 않으면 분석하지 않도록 설정할 수 있습니다.
  (`설정` 시트의 `AI 분석 동의 필수`)
- 상담 내용이 담긴 스프레드시트는 **다른 사람과 공유하지 마세요.** 웹앱은 교사 계정 권한으로
  돌기 때문에, 스프레드시트를 공유하지 않아도 학생 신청은 정상적으로 저장됩니다.
- **AI 초안은 참고용입니다.** 진단이 아니며, 판단과 상담은 선생님이 합니다.
  관심신호가 '높음'이면 학교 위기대응 절차(전문상담교사·Wee클래스·보호자 연락)를 먼저 따르세요.

## 6. 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 메뉴가 안 보임 | 스프레드시트를 새로고침. 그래도 없으면 편집기에서 `onOpen` 한 번 실행 |
| "시트가 없습니다" | **① 최초 설정 실행** 을 아직 안 누른 상태 |
| 날짜가 하나도 안 뜸 | `설정`의 운영 요일 / 예약 기간 / `상담 시간대` 확인 |
| 시간이 하나도 안 뜸 | `상담 시간대`를 `13:10, 16:30` 처럼 **쉼표로** 나열했는지 확인 |
| "항목 구성이 다릅니다" 오류 | 예전 구성으로 만든 시트에 자료가 남아 있는 경우. 자료를 다른 시트로 복사해 두고 2행 아래를 비운 뒤 다시 실행 |
| 막아 둔 날짜가 그대로 뜸 | `상담불가` 시트의 날짜 칸이 진짜 날짜 형식인지 확인 (`2026-09-14`) |
| AI 분석이 안 됨 | **③ AI 연결 테스트** 실행. 키·잔액 확인. 10분마다 자동 재시도됩니다 |
| `not scoped to a workspace` (400) | 조직 단위 키를 쓰는 경우. 워크스페이스를 지정해 키를 새로 발급하거나, 메뉴 **②-1** 에 `wrkspc_...` ID 등록 |
| AI가 자주 실패/느림 | 더 빠른 모델로 (`claude-sonnet-5` / `gemini-2.5-flash`), `AI 분석 강도`를 `low` 로 |
| `설정 시트가 어긋났습니다` | `AI 제공자` 와 `AI 모델` 이 다른 회사 것입니다. 모델을 비우면 기본값을 씁니다 |
| 메일이 안 옴 | `담당 교사 이메일` 확인. Gmail 하루 발송 한도(무료 100통)도 확인 |
| 학생이 "권한 없음" | 배포 설정의 **액세스 권한: 모든 사용자** 확인 |

로그는 Apps Script 편집기의 **실행** 탭에서 볼 수 있습니다.
